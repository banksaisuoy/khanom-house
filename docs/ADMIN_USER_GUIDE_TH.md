# คู่มือผู้ใช้งานแอดมิน — Khanom House

## 1. วิธีเข้าสู่ระบบ
1. เปิดเว็บไซต์ร้าน
2. เลื่อนลงล่างสุด → คลิก "🛡 เข้าระบบแอดมิน"
3. กรอกอีเมล + รหัสผ่าน
4. บัญชีทดลอง: admin@khanomhouse.th / <your-password>

## 2. วิธีขายผ่าน POS
1. เข้าเมนู "POS หน้าร้าน"
2. หากยังไม่มีกะ → ใส่เงินทอน → กด "เปิดกะ"
3. เลือกหมวดสินค้า (ขนมสด/แห้ง/เครื่องดื่ม)
4. กดสินค้าที่จะขาย → เพิ่มลงตะกร้า
5. ปรับจำนวนได้ในตะกร้า (− / +)
6. กด "ชำระเงิน"
7. เลือกวิธี: เงินสด / พร้อมเพย์ / บัตร
8. ใส่ยอดรับ (เงินสด) → กดยืนยัน
9. พิมพ์ใบเสร็จได้
10. หากลูกค้ายังไม่พร้อม → กด "พักบิล" → เรียกกลับมาได้ภายหลัง

## 3. วิธีจัดการออเดอร์
1. เข้าเมนู "คำสั่งซื้อ"
2. ดูออเดอร์ใน Kanban หรือตาราง
3. เปลี่ยนสถานะ: รอ → ชำระแล้ว → กำลังเตรียม → ส่งแล้ว
4. คลิกออเดอร์ → ดูรายละเอียด + พิมพ์ใบเสร็จ
5. ยกเลิกออเดอร์ → สต็อกกลับอัตโนมัติ

## 4. วิธีตรวจสลิป
1. เข้าเมนู "ตรวจสลิป"
2. ดูรูปสลิป + ยอดเงิน + เลขออเดอร์
3. ตรวจสอบยอดตรง → กด "ยืนยัน" (ออเดอร์เป็น PAID)
4. ไม่ตรง → กด "ปฏิเสธ" + ระบุเหตุผล

## 5. วิธีคืนเงิน
1. เข้าเมนู "คืนสินค้า/คืนเงิน"
2. กดสร้างคำขอ → เลือกออเดอร์ → ใส่ยอด + เหตุผล
3. ผู้จัดการอนุมัติ → สต็อกกลับ + เครดิตร้าน (ถ้าเลือก)
4. กด "ดำเนินการ" เพื่อปิดงาน

## 6. วิธีปรับสต็อก
1. เข้าเมนู "คลังสินค้า"
2. กด "ปรับสต็อก" ที่สินค้า
3. เลือก: รับเข้า / ออก / ปรับ
4. ใส่จำนวน + เหตุผล
5. บันทึก

## 7. วิธีออกใบกำกับภาษี
1. เข้าเมนู "ใบกำกับภาษี"
2. เลือกออเดอร์ → กรอกข้อมูลลูกค้า (ชื่อ, เลขภาษี, ที่อยู่)
3. กดสร้าง → พิมพ์ได้

## 8. วิธีปิดกะ
1. ในหน้า POS → กด "ปิดกะ"
2. นับเงินสดจริง → ใส่ยอด
3. ระบบคำนวณความต่าง
4. บันทึก + ดูสรุปยอด

## 9. วิธีดูรายงาน
1. เข้าเมนู "รายงาน/BI"
2. เลือก tab: ยอดขาย / สินค้า / ลูกค้า / การเงิน
3. เลือกช่วงวันที่
4. Export CSV ได้

## 10. สิทธิ์ผู้ใช้
| บทบาท | ทำได้ |
|-------|-------|
| Super Admin | ทุกอย่าง |
| Branch Manager | จัดการสาขา, อนุมัติคืนเงิน, สร้างบัตรของขวัญ |
| Cashier | POS, ขาย, สร้างออเดอร์ (ไม่มีสิทธิ์อนุมัติคืนเงิน) |
| Kitchen | ดูคิวผลิต, QC, บันทึกของเสีย |
| Rider | ดูงานจัดส่ง, อัปเดตสถานะ |
| Accountant | ดูรายงาน, บัญชี, Export |
