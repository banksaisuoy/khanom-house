# Operations Runbook — Khanom House

## Daily Opening Checklist
1. เปิด server: `bun run start` (หรือตรวจสอบว่ารันอยู่)
2. ตรวจสอบ `/api/ready` ตอบ 200
3. เปิดหน้าร้าน `/` โหลดได้
4. Login admin → ตรวจสอบ dashboard
5. เปิด POS → เปิดกะ (ใส่เงินทอนเริ่มต้น)

## Daily Closing Checklist
1. POS → ปิดกะ (นับเงินสด, บันทึกความต่าง)
2. ตรวจสอบออเดอร์ที่ยังไม่เสร็จ
3. สำรองข้อมูล: `bun run backup:db`
4. ตรวจสอบสต็อกต่ำ → สั่งซื้อเพิ่ม
5. ปิด server (ถ้าจำเป็น)

## การขายผ่าน POS
1. เข้า `/admin/pos` (PIN หรือ email)
2. เลือกหมวดสินค้า → กดสินค้าเพิ่มลงตะกร้า
3. ปรับจำนวน → กด "ชำระเงิน"
4. เลือกวิธีชำระ (เงินสด/QR/บัตร)
5. รับเงิน → กดยืนยัน → พิมพ์ใบเสร็จ
6. พักบิลได้หากลูกค้ายังไม่พร้อมจ่าย

## การตรวจสลิป
1. `/admin/slip-verification`
2. ดูรูปสลิป + ยอดเงิน + ออเดอร์
3. ตรวจสอบยอดตรง → กด "ยืนยัน"
4. หากไม่ตรง → กด "ปฏิเสธ" + ระบุเหตุผล

## การคืนเงิน
1. `/admin/refunds`
2. สร้างคำขอคืนเงิน (ระบุออเดอร์ + ยอด + เหตุผล)
3. ผู้จัดการอนุมัติ → สต็อกกลับอัตโนมัติ
4. ดำเนินการคืนเงิน → ปิดงาน

## การปรับสต็อก
1. `/admin/inventory`
2. กด "ปรับสต็อก" ที่สินค้าต้องการ
3. เลือกประเภท (รับเข้า/ออก/ปรับ)
4. ระบุจำนวน + เหตุผล
5. บันทึก → ตรวจสอบในตาราง

## การออกใบกำกับภาษี
1. `/admin/tax-invoices`
2. เลือกออเดอร์ → กรอกข้อมูลลูกค้า (ชื่อ, เลขภาษี, ที่อยู่)
3. สร้าง → พิมพ์

## PDPA — ลบข้อมูลลูกค้า
1. `/admin/customers` → เลือกลูกค้า
2. กด "ลบข้อมูล (PDPA)"
3. ข้อมูลจะถูก anonymize (ไม่ลบ hard delete)

## การแก้ปัญหา
| ปัญหา | วิธีแก้ |
|-------|--------|
| หน้าขาว | รีเฟรช, ตรวจ `/api/ready` |
| POS ไม่เปิด | ตรวจสอบกะที่เปิดอยู่ |
| สต็อกติดลบ | ปรับสต็อกใน `/admin/inventory` |
| ล็อกอินไม่ได้ | รีเซ็ตรหัสผ่าน (ดู DR runbook) |
